# Code of conduct

This project is about making software work for disabled people, and it should be a respectful place to take part in.

- Be kind and assume good intent. Disagree with ideas, not people.
- Respect people's lived experience of disability and assistive technology, and the people whose bug reports are studied here.
- Use plain, inclusive language. Don't post harassment, insults or personal attacks.
- Don't share anyone's private information.

The maintainer may edit or remove comments, and may block people who break these rules. To report a problem privately, contact the maintainer through their GitHub profile.

This code adapts the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
