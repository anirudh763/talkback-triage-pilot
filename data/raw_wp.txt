When I navigate the Reader in the Android app with a screen reader, I expect to find more context on buttons.

* The Likes button should be labeled with Like "Post Title Name" Has 77 Likes. Or Like "Post Title Name" No Likes yet. You could also communicate state here. So if a post is in a liked state, it could say: Like "Post Title Name" Pressed Has 77 Likes (or No Likes yet).

* The More button is labeled, but could use more context. "Follow Site Menu" maybe?

### Steps to reproduce the behavior

* Start Talk Back
* Open WordPress app
* Open Reader.
* Begin navigating a list of post by swiping right to navigate forward, reaching the action button area.
